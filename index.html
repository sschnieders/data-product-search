Data Product Search Tool

Search over your OpenMetadata data products
This is pre-pointed at OpenMetadata's public sandbox. Log in at sandbox.open-metadata.org with admin@open-metadata.org / admin (or your own sandbox account), then go to Settings → Security → Personal Access Tokens to generate one and paste it above. Point HOST at any OpenMetadata instance's /api root to reuse this against your own deployment. Saving loads the Domain and Tag filters below from that instance.
Type a query above and press Search — or search * to browse every data product. Use the Domain / Tag dropdowns to narrow the list.
